# FC Arena VS - Platform Overview

"FC Arena VS" is a professional eSports management platform specifically designed for FC Mobile pro players. It allows hosts (Publishers) to organize tournaments and players to compete in a structured, automated environment.

## Key Features
- **Tournament Hosting:** Publishers can create and manage tournaments (Cups) with different formats.
- **Automated Brackets:** The system handles Group Stages and Knockout Brackets automatically.
- **Match Coordination:** Players can find their opponent's WhatsApp or Messenger contact links directly on the match cards.
- **Score Reporting:** Players report scores after matches, which are then verified by Publishers.
- **Currency System:** Users use "Coins" for entry fees and prizes.
- **Real-time Updates:** Real-time data synchronization using Firebase Firestore.

## User Roles
1. **Players:** The primary users who participate in tournaments, coordinate matches, and report scores.
2. **Publishers (Hosts):** Users with permission to create tournaments, manage participants, and verify results.
3. **Admins:** Platform administrators who oversee all activities and resolve disputes.

## Navigation
- **Arena:** The dashboard for discovering and joining tournaments.
- **Matches:** Where players see their active and past match fixtures.
- **Profile:** User account management, including wallet (coins) and in-game credentials.
