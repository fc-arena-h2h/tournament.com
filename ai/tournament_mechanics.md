# Tournament Mechanics & Logic

## 1. Lifecycle
1. **Creation:** A Publisher creates a tournament using an Activation Key.
2. **Application:** Players apply to join. Hosts must manually **Approve** applicants to fill slots.
3. **Deployment:** Once full, the Host starts the tournament.
   - **Group Stage:** Players are randomized into groups of 4. Round-robin matches are created.
   - **Knockout Stage:** Brackets are generated (R16, QTR, etc.) based on participants or group winners.
4. **Scoring:** Players report results. Opponents should ideally confirm, or the Host verifies.
5. **Completion:** When the Final is over, the winner is declared.

## 2. Match Formats
- **Group + Knockout:** Groups of 4 play each other. Top players from each group advance to a single-elimination bracket.
- **Knockout:** Direct elimination from the start.

## 3. Points & Ranking (Group Stage)
- **Win:** 3 points
- **Draw:** 1 point
- **Loss:** 0 points
- **Tie-breakers:** Points > Goal Difference (GD) > Goals For (GF).

## 4. Conflict Resolution
- If a match is marked as **Disputed**, an Admin or the Host must intervene to verify the screenshot/evidence and manually set the final score.
- **Draws in Knockout:** Not allowed. Matches must have a winner (via Extra Time or Penalties in-game).
