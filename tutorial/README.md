# FC Arena VS — Official Video Tutorial Script Guide

This directory contains the complete, section-by-section video tutorial scripts for **FC Arena VS**, organized into two dedicated folders:

1. **`/tutorial/player/`** — Step-by-step video scripts for **Players** (from creating an account to playing matches, contacting opponents, and submitting results).
2. **`/tutorial/publisher/`** — Step-by-step video scripts for **Publishers / Tournament Hosts** (from creating a tournament to approving players, deploying fixtures, and managing auto-progression).

---

## Folder Structure

### 1. Player Tutorials (`/tutorial/player/`)
- `01_account_and_profile_setup.md` — Account Registration, Login & Profile Setup (IGN, UID & Social Links)
- `02_joining_tournaments.md` — Exploring Arena, Joining Public & Invited-Only Cups (`INV-XXXX`), and Joining Tournament Messenger Groups
- `03_finding_matches_and_contacting_opponent.md` — Navigating My Matches, Match ID Search (`M-XXXXXX`), and 1-Click Opponent Contact via Messenger
- `04_reporting_and_confirming_results.md` — Uploading Match Scores (`Report Result`), Confirming Opponent Scores, Penalty Rules & Dispute Handling
- `05_points_table_brackets_and_support_ai.md` — Group Standings (`PTS` & `GD`), Knockout Brackets, Global Leaderboard & Using Support AI

### 2. Publisher / Host Tutorials (`/tutorial/publisher/`)
- `01_creating_and_publishing_tournament.md` — Creating a Cup, Choosing Format (`Knockout` vs `Group + Knockout`), Demo vs Live Mode & Messenger Group Link
- `02_managing_players_and_invitation_keys.md` — Approving/Rejecting Players, Checking Player Profiles & Generating Invitation Keys (`INV-XXXX`)
- `03_group_setup_and_match_deployment.md` — `Auto Group Setup`, `Auto Match Deploy` vs `Manual Match Deploy`
- `04_verifying_results_and_auto_progression.md` — Host Score Verification, Walkover/Dispute Override & Smart Auto-Progression to Next Rounds
- `05_rules_customization_and_finishing_cup.md` — Editing Tournament Rules, Completing the Grand Final & Crowning the Champion
