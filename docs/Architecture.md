# এফসি এরিনা ভিএস (FC Arena VS) – সিস্টেম আর্কিটেকচার

## ১. সারসংক্ষেপ (Overview)
**এফসি এরিনা ভিএস** হলো একটি উচ্চ ক্ষমতাসম্পন্ন সিঙ্গেল পেজ ওয়েব অ্যাপ্লিকেশন (SPA) এবং প্রগ্রেসিভ ওয়েব অ্যাপ (PWA), যা বিশেষভাবে **FC Mobile** (FIFA Mobile) গেমারদের জন্য তৈরি। এর মাধ্যমে প্লেয়াররা টুর্নামেন্টে অংশ নিতে পারে, ১v১ সরাসরি চ্যালেঞ্জ খেলতে পারে এবং ডিজিটাল ক্যাশিয়ারের মাধ্যমে টাকা/কয়েন লেনদেন করতে পারে।

সম্পূর্ণ সিস্টেমটি ক্লায়েন্ট-সাইড রিঅ্যাক্ট (React 19) ফ্রেমওয়ার্ক এবং গুগল ফায়ারবেস (Firestore ডাটাবেজ এবং Authentication) এর ওপর ভিত্তি করে তৈরি করা হয়েছে।

## ২. প্রযুক্তিগত কাঠামো (Technology Stack)

| স্তর (Layer) | ব্যবহৃত প্রযুক্তি (Technology) | উদ্দেশ্য ও ভূমিকা |
|---|---|---|
| **ফ্রন্টএন্ড ফ্রেমওয়ার্ক** | React 19 (TypeScript) | ইউজার ইন্টারফেস (UI), স্টেট ম্যানেজমেন্ট ও বিভিন্ন পেজের সমন্বয় |
| **বিল্ড ও বান্ডলার** | Vite 6 | অত্যন্ত দ্রুত ডেভ-সার্ভার ও প্রোডাকশন বিল্ড অপটিমাইজেশন |
| **ডিজাইন ও স্টাইলিং** | Tailwind CSS v4 + Neumorphic Tokens | সফট-ইউআই (নিয়োমর্ফিজম) থিম (`nm-flat`, `nm-inset`, `nm-pressed`) |
| **ডাটাবেজ** | Google Cloud Firestore | রিয়েল-টাইম ডাটা সিংক্রোনাইজেশন (`onSnapshot`) ও ট্রানজ্যাকশন |
| **অথেনটিকেশন** | Firebase Authentication | প্লেয়ার ও অ্যাডমিনদের নিরাপদ লগইন এবং রোল ভিত্তিক সিকিউরিটি |
| **অফলাইন ও পিডব্লিউএ** | Vite PWA Plugin + Service Worker | অফলাইনেও অ্যাপ চালু থাকা, মোবাইল ইনস্টলেশন বাটন ও ব্যাজ নোটিফিকেশন |
| **আইকন** | Lucide React | আধুনিক, ক্লিয়ার এবং দ্রুত লোড হওয়া ভেক্টর আইকন |

## ৫. ফায়ারবেস কানেকশন ও লং-পোলিং ব্যবস্থা

ব্রাউজারে বা মোবাইল নেটওয়ার্কে যাতে `FirebaseError: [code=unavailable]` এরর না আসে, সেজন্য ফায়ারবেস ক্লায়েন্টে সরাসরি লং-পোলিং সক্রিয় করা হয়েছে:
```typescript
export const db = initializeFirestore(
  app,
  {
    experimentalForceLongPolling: true,
  },
  databaseId || undefined
);
```
এর ফলে ওয়েবসকেট ফেইল করলেও অ্যাপের ব্যাকগ্রাউন্ডে সরাসরি নির্ভরযোগ্য HTTPS রিকোয়েস্টের মাধ্যমে নিরবচ্ছিন্নভাবে ডাটা আদান-প্রদান হয়।

## ৬. রোল ও ইউজার পারমিশন (RBAC)
অ্যাপে প্রধানত ৩ ধরনের ইউজার রোল রয়েছে:
1. **প্লেয়ার (`player`)**: টুর্নামেন্টে যোগ দেওয়া, ১v১ চ্যালেঞ্জ খেলা, টাকা জমা/তোলার আবেদন করা।
2. **পাবলিশার (`publisher`)**: নিজের টুর্নামেন্ট তৈরি ও পরিচালনা করা, রেজিস্ট্রেশন যাচাই করা।
3. **অ্যাডমিন (`admin`)**: সম্পূর্ণ অ্যাপ নিয়ন্ত্রণ, লেনদেন অ্যাপ্রুভ/রিজেক্ট, জালিয়াতি প্রতিরোধ প্যানেল ও ব্যান/আনব্যান করার পূর্ণ ক্ষমতা।
